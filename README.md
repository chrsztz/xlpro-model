在 **学校博士工作室** 与 **国防科技大学计算机博士** 合作，围绕 **AI 深度学习与云计算** 进行开发，研究主题为 **基于深度学习的钢琴指法预测**。  

---

## 🔬 研究目标  
本研究旨在利用深度学习技术 **预测钢琴谱中的指法**，并优化模型的精度和泛化能力。  

---

## 📊 数据处理  

1. **数据集选取**：使用 **PIG 数据集** 进行钢琴谱序列化处理。  
2. **数据预处理**：  
   - 对 **音名进行归一化与映射**  
   - 提取 **多维特征**，包括：
     - 🎵 **演奏速度**
     - 🎼 **音符稠密度**
     - 🎶 **和弦结构**
     - ⏳ **音符时长**
     - 🔢 **音高信息**
3. **数据增强**：  
   - 采用 **SMOTE 过采样**  
   - **对称镜像增强** 以提升泛化能力  

---

## 🧠 模型构建  

1. **特征融合**：  
   - 采用 **Word2Vec** 进行特征向量化  
   - **标准化数值特征** 以增强模型稳定性  
2. **深度学习架构**：  
   - 采用 **BiLSTM（双向长短期记忆网络）**，捕捉音符序列的 **前后依赖关系**  
   - 引入 **注意力机制** 强化 **关键特征权重分配**  
   - 结合 **条件随机场（CRF）**，优化指法序列的 **全局标注精度**  

---

## 🎯 训练与测试结果  

✅ **模型准确率**：**89%**  
📉 **损失率**：**0.63**  

目前，模型已成功 **部署至云端服务器**，并进入 **测试阶段**。  
仍需继续优化 **算法框架**，以进一步提升模型性能与预测准确率。  

---
